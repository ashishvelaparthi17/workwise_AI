# WorkwiseAI Internal Multi-Agent Copilot

This repository captures the product backlog for the WorkwiseAI internal multi-agent copilot built with Python, FastAPI, and LangGraph. Each story is ready to use as a GitHub issue so work can begin immediately.

## Contents
- [`.github/issues/`](.github/issues/): Individual, import-ready GitHub issue markdown files organized by epic and story.

## Using the Backlog
### Option 1: Create issues automatically (recommended)
1. Push this repository to GitHub.
2. Navigate to **Actions → Create backlog issues → Run workflow**.
3. (Optional) Enable the `dry_run` input to preview which issues would be created.
4. Run the workflow to populate your repository’s Issues tab with one entry per backlog item. Existing issues with the same title are skipped so you can re-run the workflow safely.

### Option 2: Import issues manually
1. From your GitHub repository, navigate to **Issues → New Issue → Import** and drag the markdown files from [`.github/issues/`](.github/issues/).
2. Apply labels or assignees as you import so teams can pick up work one story at a time.
3. Track progress directly in GitHub Projects or your preferred tooling once the issues are created.
